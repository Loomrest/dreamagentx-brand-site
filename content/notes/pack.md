## 先说清楚区别

连载是免费的，而且会一直免费。它讲清楚**该怎么做**。

完整课程包解决的是另一件事：**照着就能做出来**。

下面是逐项对照，看完再决定要不要。

| | 连载（免费） | 完整课程包 |
|---|---|---|
| 结构 | 单篇独立成文 | 体系化，有学习路径和交叉索引 |
| 深度 | 讲「怎么做」 | 加上「为什么、边界在哪、什么时候不该这么做」 |
| 案例 | 每篇一个 | 每章三到五个，含反面案例 |
| 代码 | 关键片段与骨架 | 完整可运行项目，锁定依赖版本 |
| 清单 | 无 | 自检清单、避坑清单、简历措辞对照表 |
| 练习 | 小程序自测题 | 加上动手实验与参考答案 |
| 更新 | 发布后不回改 | 持续勘误更新，一次购买后续都能拿到 |

## 包含什么

**三个项目的完整实现**：可运行的代码、环境配置说明、常见报错与解决方法。

**验证方法**：怎么证明你的项目真的有效，而不是「我试了几个感觉还行」。这部分是大多数教程缺失的。

**简历与讲解**：怎么把项目写进简历、面试被追问时的回答框架、三分钟项目讲解脚本。

**自检清单**：数据准备、上线前检查、项目完整度自检。
